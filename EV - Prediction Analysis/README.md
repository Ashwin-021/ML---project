# EV Cars in India – Data Analysis

## 📌 Project Overview

This project analyzes electric vehicles available in India based on their **price, driving range, power, and battery capacity**.

## 📊 Dataset

The dataset contains **26 EV cars** with the following columns:

* Brand
* Model
* Price
* Range
* Power
* Battery

## 🎯 Objectives

* Analyze EV prices and performance.
* Compare driving ranges of different EV models.
* Study the relationship between battery capacity and range.
* Compare power and other specifications.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📈 Analysis

The project includes **data cleaning, exploratory data analysis (EDA), and visualization** to understand EV specifications and market trends.
