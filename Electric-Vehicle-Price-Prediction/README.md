# ⚡ Electric Vehicle Price Prediction Using Machine Learning

## 📌 Overview
This project predicts the price of Electric Vehicles using Machine Learning. The dataset contains EV brand, model, price, range, power, and battery information.

## 📊 Dataset
- Brand
- Model
- Price
- Range
- Power
- Battery

## 🛠️ Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🔄 Workflow
Data Collection → Data Cleaning → EDA → Feature Selection → Model Training → Prediction → Evaluation

## 🎯 Target
**Price**

## 🚀 Goal
To analyze EV specifications and build a Machine Learning model for predicting electric vehicle prices.
