
# Data Cleaning & Feature Scaling using ML

## 📌Overview

This project focuses on **data preprocessing techniques** used in Machine Learning. It covers data cleaning and feature scaling to prepare customer data for analysis and machine learning models.

## 🎯 Objectives

* Clean and preprocess the dataset.
* Handle missing and unnecessary data.
* Explore the customer dataset.
* Apply feature scaling techniques.
* Prepare data for Machine Learning.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

## 📊 Dataset

The project uses a **customer churn dataset** containing customer information and features related to customer retention.

## 🔍 Tasks Performed

### Data Cleaning

* Loaded and explored the dataset.
* Checked for missing values.
* Removed unnecessary columns.
* Prepared the data for analysis.

### Feature Scaling

* Selected numerical features.
* Applied feature scaling techniques.
* Standardized numerical values for Machine Learning.
